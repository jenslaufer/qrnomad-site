Warum er nie abläuft: Dein Link steckt direkt im Code. Beim Scannen läuft nichts über unsere Server.

Source: https://qrnomad.com/de/

## Zwei Arten von Codes. Du entscheidest vor dem Druck.

### Statischer Code

1. Link einfügen.
2. Code erstellen.
3. Als PNG oder SVG herunterladen. Fertig.

Dein Link steckt im schwarz-weißen Muster selbst. Das Handy liest ihn und öffnet direkt deine Seite. Wir sitzen nicht dazwischen. Deshalb können wir deinen Code nicht abschalten, selbst wenn wir wollten.

Der Haken: Nach dem Druck lässt sich der Link nicht mehr ändern.

### Dynamischer Code

1. Code erstellen und „änderbar“ wählen.
2. Drucken. Der Code zeigt auf eine feste QRnomad-Adresse.
3. Ziel ändern, wann immer du willst. Jeder gedruckte Code folgt.

Der Druck bleibt. Das Ziel zieht weiter. Daher der Name: QRnomad.

## FAQ

### Ist der kostenlose QR-Code wirklich kostenlos?

Ja. Kein Konto, kein Test-Abo, keine Kreditkarte. Du lädst die Datei herunter, und sie gehört dir. Unter dem Code steht klein „qrnomad.com“ – das siehst du schon in der Vorschau. Änderbare Codes kommen ohne diesen Hinweis.

### Hört mein kostenloser Code irgendwann auf zu funktionieren?

Nein. Ein statischer Code trägt deinen Link im Muster selbst. Beim Scannen öffnet das Handy direkt deine Seite. Unsere Server sind nicht beteiligt, also können wir ihn nicht abschalten. Er geht nur dann nicht mehr, wenn die verlinkte Seite offline ist.

### Was ist der Unterschied zwischen statisch und dynamisch?

Statisch: Der Link steckt direkt im Code. Kostenlos und unbegrenzt haltbar, aber nach dem Druck fest.

Dynamisch: Der Code enthält eine feste QRnomad-Adresse, die auf deinen Link weiterleitet. Du änderst das Ziel jederzeit und siehst die Scans. Für diese Weiterleitung zahlst du.

### Kann ich einen kostenlosen Code später änderbar machen?

Nein. Beim statischen Code ist der Link fest eingebaut. Wenn sich dein Link ändern könnte, mach den Code vor dem Druck änderbar.

### Was passiert mit meinen dynamischen Codes, wenn ich nicht verlängere?

Sie leiten nicht mehr weiter, sobald dein bezahltes Jahr endet. So funktionieren dynamische Codes überall: Der gedruckte Code zeigt auf unsere Adresse, und die Weiterleitung läuft so lange wie dein Plan.

Überraschen werden wir dich nicht. Es gibt keine automatische Verlängerung: Wir schreiben dir 30 und 7 Tage vor Ablauf, und nach Ablauf zeigen deine Codes noch 30 Tage einen Hinweis mit deinem Link. Alle Codes samt Ziel-Links kannst du jederzeit exportieren.

Soll ein Code ohne Plan für immer funktionieren, nimm einen kostenlosen statischen Code, der auf eine Seite zeigt, die dir gehört.

### Gibt es ein Monatsabo oder eine Testphase?

Nein. Es gibt einen Plan: 199 € im Jahr, einmal im Voraus bezahlt. Keine Testphase, die still zum Abo wird. Kein automatisches Upgrade. Du siehst den Preis vor dem Kauf, und genau den zahlst du.

### Was heißt „unbegrenzt, Fair Use“?

Du erstellst so viele dynamische Codes, wie dein Geschäft braucht. Fair Use schließt Missbrauch aus, nicht normale Nutzung.

### Was zeigt die Scan-Statistik?

Wie oft dein Code pro Tag gescannt wird, ungefähr woher und mit welchem Gerätetyp.

### Welches Dateiformat brauche ich?

SVG für den Druck. Es bleibt in jeder Größe scharf. PNG für Website, E-Mail und Office-Dokumente.

### Warum heißt es QRnomad?

Der gedruckte Code bleibt, wo er ist. Sein Ziel zieht mit dir weiter: zur neuen Karte, zur neuen Website, zum nächsten Objekt.
