## Two kinds of codes. You pick before you print.

### Free static code

1. Paste your link.
2. Create your code.
3. Download PNG or SVG. Done.

Your link is stored inside the black-and-white pattern. A phone reads it and opens your page directly. We are not in between. So we can’t switch your code off, even if we wanted to.

The catch: once printed, the link can’t change.

### Editable dynamic code

1. Create your code and choose “editable”.
2. Print it. The code points to a fixed QRnomad address.
3. Change the destination whenever you want. Every printed copy follows.

The print stays put. The destination moves. That’s the idea behind the name: QRnomad.

## FAQ

### Is the free QR code really free?

Yes. No account, no trial, no credit card. You download the file, and it’s yours. A small “qrnomad.com” caption sits under the code; you see it in the preview. Editable codes come without it.

### Will my free code ever stop working?

No. A static code holds your link inside the pattern itself. When someone scans it, their phone opens your link directly. Our servers are not involved, so we can’t switch it off. It only stops working if the page it links to goes offline.

### What’s the difference between static and dynamic?

A static code holds your link directly. It’s free and works forever, but the link is fixed once printed.

A dynamic code holds a fixed QRnomad address that forwards to your link. You can change the link anytime and see scan stats. That forwarding is what the plan pays for.

### Can I turn a free code into an editable one later?

No. The link is baked into a static code. If your link might change, make the code editable before you print.

### What happens to my dynamic codes if I don’t renew?

They stop forwarding when your paid year ends. That’s how dynamic codes work everywhere: the printed code points to our address, and the forwarding runs as long as your plan does.

We won’t surprise you. There is no automatic renewal: we email you 30 and 7 days before your year ends, and for 30 days after that your codes show a notice with your link. You can export all your codes and their destination links anytime.

If a code must work forever without a plan, use a free static code that points to a page you control.

### Is there a monthly plan or a free trial?

No. There’s one plan: $199, paid once a year. No trial that quietly turns into a subscription. No automatic upgrade to a bigger plan. You see the price before you pay, and that’s the price you pay.

### What does “unlimited, fair use” mean?

Create as many dynamic codes as your business needs. Fair use rules out abuse, not normal business use.

### What do the scan stats show?

How many scans you get per day, roughly where they come from, and which kind of device.

### Which file format should I use?

SVG for print. It stays sharp at any size. PNG for websites, emails and Office documents.

### Why the name QRnomad?

The printed code stays where it is. Its destination travels with you: to the new menu, the new website, the next listing.
